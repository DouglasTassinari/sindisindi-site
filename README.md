# SINDISINDI/RS — Protótipo institucional

Protótipo navegável com páginas independentes, dez páginas de notícias demonstrativas e área de consulta de acordos coletivos.

Abra `index.html` para visualizar localmente. Antes da publicação oficial, valide textos, datas, instrumentos coletivos, links e direitos de uso das imagens.

A página `acordos.html` direciona para registros públicos oficiais e está preparada para receber PDFs autorizados no próprio repositório. Os PDFs ainda não foram incorporados localmente.
